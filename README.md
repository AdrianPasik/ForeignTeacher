# Foreign Teacher

## What's the point

I was trying to learn foreign language. I didn't have time to study with books, I've needed something that I can use when I'm doing daily tasks.
Unfortunately all of free vocabulary learning tools (which I knew of) didn't match my requirement. Either vocabulary was really silly or there was something wrong with learning algorithms.
One main problem was it was translating from foreign to known. **I wanted from known to foreign (which is harder)**

## Solution

This tool will help you memorize vocabulary of any defined language (it will be only for PL as known language for time being).


## Usage

This is meant to be working without any database. As persistence layer, I am using local storage (which is enough for this task).
```
ng serve
```

Or used deployed version. Anything will do since it does not require any backend
